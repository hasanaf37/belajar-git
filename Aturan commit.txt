turan dan Cara Mengubah File GitHub dari Lokal dan GitHub Langsung



Mengubah File dari Lokal (Local Repository):

Pastikan repository GitHub sudah di-clone ke komputer menggunakan perintah:

git clone <url-repository>


Buka folder proyek tersebut di editor (misalnya VS Code).

Lakukan perubahan pada file yang diinginkan.

Simpan perubahan, lalu jalankan perintah:

git add .
git commit -m "Menambahkan perubahan baru"
git push origin main


Setelah itu, perubahan akan dikirim (push) ke GitHub dan tersimpan di repository utama.
